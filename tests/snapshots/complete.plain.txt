  Beautiful Markdown in your terminal.

  Bold, italic, strike, inline code, and a link <https://github.com/kotsutsumi/mdsee>.

  Installation
  ────────────────────────────────────────────────────────

  Install with Homebrew or cargo:

  ╭─ sh ──────────────────────────────────────────────────
  │ brew install owner/tap/mdsee
  ╰───────────────────────────────────────────────────────

  Features
  ────────────────────────────────────────────────────────

  • GFM Markdown
  • Syntax highlighting
  • Terminal hyperlinks
  • Tables
  • Reader mode
